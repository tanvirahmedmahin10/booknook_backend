# 📚 BookNook Backend

A RESTful backend API for **BookNook**, a library management application where users can explore books, manage their collections, and borrow or return books.

## ✨ Features

- Manage books (Add, Update, Delete).
- Get all books and individual book details.
- Manage personal book collections.
- Borrow and return books.
- JWT authentication with Better Auth.
- MongoDB database integration.

## 🛠️ Technologies

- Node.js
- Express.js
- MongoDB
- Better Auth
- JOSE
- Vercel

## ⚙️ Installation

**1. Clone the repository**

```bash
git clone https://github.com/tanvirahmedmahin10/booknook_backend.git
cd booknook_backend
```

**2. Install dependencies**

```bash
npm install
```

**3. Create a `.env` file**

```env
MONGO_DB_URL=your_mongodb_connection_string
CLIENT_URL=https://booknook-frontend-seven.vercel.app
```

**4. Start the server**

```bash
node index.js
```

Server runs at `https://booknook-backend-wine.vercel.app`.
